## 🌟 Highlights & Features

- **Text-Focused Hero Showcase:** Elegant presentation highlighting academic status, location (Udupi, Karnataka), verified core ratings, and primary action links.
- **Orange & Charcoal Theme:** Hand-crafted, modern engineering aesthetic with high-contrast WCAG 2.1 AA accessibility.
- **Dark / Light Theme Switcher:** Defaults to Light Mode per preference, with instant toggle to Dark Mode (persisted in `localStorage`).
- **Verified Skill Meters:** Factual representation of foundational skills:
  - **Java:** Level `Basic`
  - **Python:** Level `Basic`
  - **C:** Level `Basic`
- **Learning Journey & Active Explorations:** Authentic academic coursework and lab experiments at PIM Udupi (Data Structures, OOP, MySQL schemas, scientific Python with NumPy, responsive web design) with interactive category filtering tabs.
- **Interactive Resume Modal & Print-to-PDF:** One-click modal preview featuring a clean resume with automated `@media print` styling for generating a professional 1-page PDF.
- **Instant Contact & Clipboard Utilities:** 1-click copy for email (`ankithanku988@gmail.com`) and phone (`8277069598`) with toast feedback, plus pre-formatted mailto message launcher.
- **Responsive Navigation:** Sticky header navigation on desktop and an accessible sliding drawer on mobile devices.

## 🚀 How to Open and Run

Since this project is built entirely with pure HTML, CSS, and JavaScript:

1. **Directly in Any Browser:**  
   Double-click `index.html` or open it with Google Chrome, Microsoft Edge, Mozilla Firefox, or Brave.

2. **Publishing to GitHub Pages:**
   - Initialize git in this folder or upload `index.html`, `style.css`, and `main.js` to your GitHub repository: [`ankithanku988-source`](https://github.com/ankithanku988-source).
   - Go to your repository settings -> **Pages** -> Select `main` branch `/ (root)` -> Click **Save**.
   - Your portfolio will be live at `https://ankithanku988-source.github.io/<repo-name>/`.
